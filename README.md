# 📚 Рабочий кабинет

Личное веб-приложение для учёбы и хобби: таймер задач, план дня, статистика с помощником, фоновые звуки, карточки для языков, чтение текстов с подсветкой слов, цели хобби и дневник самочувствия.

Работает прямо в браузере, на компьютере и на телефоне. Сервер не нужен.

## Что умеет

| Раздел | Возможности |
|---|---|
| ⏱️ **Таймер сверху** | на любой странице: выбор задачи (подставляется по разделу), секундомер или Pomodoro, время видно всегда |
| 🎮 **Игра** | уровень и опыт за всё полезное, 3 задания дня, 15 достижений (в «Статистике») |
| 🗓️ **Календарь** | месяц: выполненность плана и настроение по дням (время — по желанию), подробности дня, переход к плану |
| ⏱️ **Сегодня** | задачи с категориями (языки, учёба, хобби…), блок «Продолжить» с недавними задачами (в открытой категории — её задачи), секундомер и **Pomodoro** (25/5, длинный перерыв после 4-го), кольцо дневной цели, история за день, ручное добавление и правка времени |
| 📅 **План** | расписание на день по времени, отметки «сделано», подсветка текущего блока, запуск таймера прямо из плана, копирование плана со вчера или с прошлой недели, перенос незавершённого с прошлых дней |
| 📊 **Статистика** | день / неделя / месяц, листание периодов, график по дням или часам с линией цели, разбивка по категориям и задачам, сравнение с прошлым периодом, фильтр по задаче или категории (например, только «Учёба»), **серия дней подряд** 🔥, календарь активности за 18 недель |
| 🎧 **Фоновые звуки** | 13 звуков: два lo-fi (обычный и ночной), пианино, эмбиент, дождь, гроза, камин, лес, ночь со сверчками, океан, белый / розовый / коричневый шум. Можно включить несколько сразу, у каждого своя громкость, все выровнены по громкости. **Не прерываются** при переходе между разделами |
| 🗂️ **Языки → Карточки** | колоды «слово — перевод — пример», интервальное повторение (упрощённый SM-2), озвучка 🔊, массовое добавление списком (`слово - перевод`), пример колоды |
| 📖 **Языки → Чтение** | вставляешь текст и нажимаешь на слово: **перевод подставляется сам** (с вариантами). Есть перевод всего предложения и **значения слова по частям речи** с примерами (для английского). Слово добавляется в карточки вместе с предложением-примером. Слова из колод подсвечиваются, можно отмечать знакомые и выделять целые фразы |
| ✨ **Языки → Уроки** | игровые уроки от нейросети под твой уровень: тест на уровень (A1–C1), 8 заданий (выбор, вставить слово, собрать предложение, перевод с проверкой), жизни, XP и серии, работа над ошибками, совет повысить или понизить уровень. В уроки попадают слова, которые трудно даются в карточках |
| 🎨 **Хобби** | цели с числом («12 книг») или по шагам (чек-лист), отметки прогресса, сроки, достигнутые цели |
| 🌿 **Самочувствие** | отметки настроения, энергии и стресса (1–5), сон в часах и минутах (или «легла / встала»), теги, заметки; график за 30 дней; «что связано с настроением». Упражнения: дыхание «квадрат», 4-7-8, спокойное дыхание (с анимацией), заземление 5-4-3-2-1, пауза для тела, «три хороших вещи», разгрузка мыслей; дневник |
| 💛 **Поддержка** | «зачем я это делаю», вопрос дня с историей ответов, «маленькая я» — напоминание причин, прогресс, маленький шаг, разговор с нейросетью |
| 📚 **Встроенная база** | 33 темы грамматики A1–C1 с тренировками и тестами по уровням, тест на уровень, 14 текстов A1–C1 с вопросами на понимание, 8 готовых наборов слов |
| 💡 **Помощник** | на главной советы на сегодня, в статистике обзор недели: динамика времени, забытые категории, выполнение плана, хобби без движения, связь учёбы, сна и прогулок с настроением. Работает по правилам, без нейросети |
| ⚙️ **Настройки** | дневная цель, длительность помидоров, звук сигнала (6 вариантов), тема (светлая / тёмная / как в системе), категории, архив задач, **экспорт и импорт JSON** |

Горячие клавиши: `Пробел` запускает и останавливает таймер, `M` включает и выключает звук, `1`–`7` переключают разделы. В карточках `Пробел` переворачивает карточку, а `1`–`4` ставят оценку.

## Нейросеть (бесплатно)

Уроки, «Объяснить в контексте» в «Чтении» и «Сгенерировать колоду» работают через бесплатную нейросеть. Подключение: **Настройки → «Нейросеть»**.

- **OpenRouter** работает без VPN. Ключ берётся на [openrouter.ai/settings/keys](https://openrouter.ai/settings/keys). По умолчанию стоит `openrouter/free`: сервис сам выбирает работающую бесплатную модель. Лимит около 50 запросов в день, урок занимает 2–4 запроса.
- **Gemini** даёт лучшее качество, но в России работает только через VPN. Ключ берётся на [aistudio.google.com/apikey](https://aistudio.google.com/apikey). Свежую модель кабинет выбирает сам.
- **Свой адрес**: любой OpenAI-совместимый сервер, например Ollama на ноутбуке.

Ключ хранится только в браузере. В код, на GitHub и в файл экспорта он не попадает.

## Как это устроено (простыми словами)

- Это **одна HTML-страница** со скриптами. При переходе между разделами страница не перезагружается, меняется только содержимое. Поэтому музыка и таймер не обрываются (в Streamlit страница перезапускается при каждом действии).
- **Данные** хранятся в `localStorage`, то есть в памяти браузера на твоём устройстве. На сервер ничего не отправляется. Исключение — раздел «Чтение»: при автопереводе слово отправляется в бесплатный сервис [MyMemory](https://mymemory.translated.net/). По кнопкам туда же уходит предложение, а слово ещё и в словарь [dictionaryapi.dev](https://dictionaryapi.dev/). Автоперевод можно выключить в настройках.
- **Таймер** запоминает время старта, поэтому переживает даже перезагрузку страницы.
- **Звуки** генерируются кодом прямо в браузере через Web Audio API. Чужих записей нет, поэтому вопросов с лицензиями тоже нет.
- **Офлайн**: service worker (`sw.js`) сохраняет файлы, и после первого открытия сайт работает без интернета.

## Запуск на своём компьютере

Самый простой способ: дважды щёлкнуть по `index.html`, и он откроется в браузере. Всё работает, кроме офлайн-режима.

Правильный способ: запустить маленький сервер в папке проекта.

```bash
cd ~/study-workspace
```

```bash
python3 -m http.server 8000
```

Потом открыть в браузере http://localhost:8000. Остановить сервер: `Ctrl+C`.

> ⚠️ Данные привязаны к адресу. У `file://…/index.html`, `http://localhost:8000` и сайта на GitHub Pages **разные** хранилища. Чтобы перенести данные, сделай «Экспорт» в одном месте и «Импорт» в другом.

## Бесплатный деплой на GitHub Pages

После этого кабинет будет доступен по адресу `https://<твой-логин>.github.io/study-workspace/`, в том числе с телефона.

### Вариант 1: через терминал (`gh` уже настроен)

```bash
cd ~/study-workspace
```

```bash
gh repo create study-workspace --public --source=. --push
```

```bash
gh api -X POST repos/{owner}/study-workspace/pages -f "source[branch]=main" -f "source[path]=/"
```

Через 1–2 минуты сайт заработает. Адрес можно посмотреть так:

```bash
gh api repos/{owner}/study-workspace/pages --jq .html_url
```

### Вариант 2: через сайт GitHub

1. Создай на github.com новый репозиторий `study-workspace` (Public).
2. Выполни команды, которые GitHub покажет в разделе «…or push an existing repository from the command line».
3. В репозитории открой **Settings → Pages**. В разделе *Build and deployment* выбери *Source: Deploy from a branch*, *Branch: `main`*, папка `/ (root)`, и нажми **Save**.
4. Через пару минут сверху появится ссылка на сайт.

### Как обновить сайт после изменений

```bash
git add -A && git commit -m "Обновление" && git push
```

GitHub Pages обновится сам за 1–2 минуты. Если на телефоне видна старая версия, закрой и снова открой приложение. Если поменялся список файлов, увеличь номер `CACHE` в `sw.js` (`kabinet-v1` → `kabinet-v2`).

### Кто увидит сайт?

Публичный сайт откроет любой, у кого есть ссылка, но **увидит пустой кабинет**: у каждого человека данные хранятся в его собственном браузере. В репозитории лежит только код, личных данных там нет. Бесплатный GitHub Pages работает только с публичными репозиториями.

## Установка на телефон

1. Открой ссылку на сайт в браузере телефона.
2. **Android (Chrome):** меню ⋮ → «Установить приложение» или «Добавить на гл. экран».
   **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
3. Кабинет появится среди приложений, будет открываться без адресной строки и работать без интернета.

## Ограничения

- **Синхронизации между устройствами нет.** Телефон и компьютер хранят данные отдельно, переносить их можно через экспорт и импорт. Автоматическая синхронизация потребует сервер (например, Supabase), это отдельная задача.
- **Регулярно делай экспорт.** Если очистить в браузере «данные сайтов», всё сотрётся. Приложение само напомнит, если копии давно не было.
- **Фоновые звуки на iPhone** могут замолкать, когда экран заблокирован. Так iOS обращается со звуком из браузера.
- **Первое включение Lo-fi, дождя или океана** занимает несколько секунд: звук генерируется. Потом последние выбранные звуки готовятся заранее, сразу после открытия страницы.
- **Чтение** разбивает текст на слова по пробелам, поэтому для китайского и японского нажатие выделяет целую фразу.

## Структура проекта

```
index.html            — страница и подключение скриптов
css/style.css         — оформление, светлая/тёмная тема, адаптивная вёрстка
js/utils.js           — даты, форматирование, всплывающие уведомления
js/store.js           — данные в localStorage, экспорт/импорт
js/timer.js           — секундомер и Pomodoro
js/audio.js           — генерация фоновых звуков и сигналов (Web Audio API)
js/charts.js          — графики на SVG
js/stats-data.js      — подсчёты для статистики и серии дней
js/icons.js           — набор линейных SVG-иконок
js/ai.js              — подключение нейросети (Gemini / OpenRouter / свой адрес)
js/insights.js        — «помощник»: советы и обзор недели по правилам
js/views/*.js         — разделы: home, plan, stats, cards, read, lessons, hobby, mind, settings
js/app.js             — переключение разделов, плеер, окна, горячие клавиши
sw.js                 — офлайн-режим
manifest.webmanifest  — установка на телефон (PWA)
icons/                — иконки
```

Библиотеки и сборка не нужны: это обычные HTML, CSS и JavaScript.
